# 🤖 Neural Network from Scratch – Iris Dataset Classifier

A fully custom feedforward neural network built using **NumPy**, trained on the **Iris flower classification dataset**. This project demonstrates how to implement key neural network components — forward propagation, backpropagation, and weight updates — from scratch without any deep learning libraries like TensorFlow or PyTorch.

---

## 📌 Features

- ✅ Manual weight and bias initialization (He/Xavier)
- ✅ Forward and backward propagation
- ✅ Activation functions: **Sigmoid** and **ReLU**
- ✅ Mean Squared Error loss (option to upgrade to Cross-Entropy)
- ✅ Training visualization using Matplotlib
- ✅ Multi-class classification with One-Hot Encoding
- ✅ Evaluation on the Iris dataset

---

## 📁 Dataset

Uses the **Iris dataset** from `sklearn.datasets`:
- 150 samples
- 4 features per sample
- 3 output classes (Setosa, Versicolor, Virginica)
